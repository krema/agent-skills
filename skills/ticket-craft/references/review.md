# Review checks

Judge the artifact's ability to guide its intended reader. Do not score field counts, sentence length, or acronym compliance.

| Check | Failure signal | Repair |
|---|---|---|
| Purpose | Reader cannot identify the beneficiary or intended result | Clarify need using supplied evidence; label hypotheses |
| Granularity | Epic is treated as executable without a bounded assignment, or subtask claims the full outcome | State its role and link children/parent |
| Meaning | Two reasonable readings lead to different accepted results | Define term or raise the consequential decision |
| Verification | “Fast,” “works,” or “user friendly” cannot be accepted objectively | Obtain measurement conditions or define observable behavior; do not invent a threshold |
| Scope | Criterion silently adds a capability or proposed design becomes mandatory | Align with the request or label proposal |
| Hierarchy | Children omit a parent criterion, contradict each other, or duplicate ownership | Map contribution and repair the gap; not all user value requires a separate child |
| Agent pickup | Required conversation, reference, environment, or interface is unavailable | Capture the decision/excerpt or disclose the blocked dependency |
| Test alignment | Check enforces a private implementation choice or misses promised behavior | Revise check or resolve the intended requirement |
| Context | Long repeated material changes no task decision | Remove it or replace it with a purposeful source pointer |
| Readiness | Unknown correctness-changing behavior is presented as settled | Mark needs refinement and name the decision; continue independent work |

Acceptance criteria describe the item; a team's Definition of Done describes broader quality expectations; outcome measures evaluate real-world benefit. Keep all three consistent without treating them as interchangeable.

For an agent handoff dry run, ask the executor to restate the expected outcome, identify the first useful inspection/action, and map checks to criteria. Inspect actual implementation or investigation results when available. Restatement alone does not establish successful execution. Compare human and agent interpretations against the same agreed behaviors; measure clarification needs, scope deviations, correctness, and effort if evaluating effectiveness.
