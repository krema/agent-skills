This is a targeted comparison with [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD) and [Compound Engineering Plugin](https://github.com/EveryInc/compound-engineering-plugin), not a repository-wide issue screen for either. I searched for instruction, workflow, handoff, skill invocation, approval, and guidance conflicts, then read the linked primary issues and changes. ## What this changes

The Superpowers cases already support checking discovery, phase gates, child context, and completion evidence. These cases add distinct checks for **cross-skill entry**, **same-task recursion**, **return to a parent workflow**, and **contradictory guidance loaded at action time**. The approval-side-effect report adds a boundary case for inspecting nested writes. These are diagnostic branches in the skill, not a claim that any single wording prevents all noncompliance.

The strongest comparative repair evidence here is Compound's merged changes with fixture checks and BMAD's small controlled delegation trial. The latter remains open and narrow. The #1119 repair is merged, but its PR does not show a completed behavioral trial. None is a fresh trial of *this* diagnostic skill.
